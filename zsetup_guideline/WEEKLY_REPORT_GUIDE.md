# 📅 WEEKLY REPORT FEATURE - USER GUIDE

## Overview
The Weekly Report feature allows administrators to view detailed weekly statistics across all assistance programs, with daily breakdown of data and interactive charts.

---

## 🎯 How to Access Weekly Reports

### Step 1: Go to Reports
1. Login to admin dashboard
2. Click **"Reports"** in the sidebar

### Step 2: Select Weekly Period
1. Look at the **"Period"** dropdown in the filter section
2. Select **"Weekly"** option
3. Choose which week you want to view from the **"Week"** dropdown

### Step 3: View Your Data
The weekly report will display:
- 📊 Statistics for the selected week
- 📈 Daily breakdown charts
- 📋 List of approved and pending applications

---

## 📊 What's Included in Weekly Reports

### Weekly Statistics Cards (Top of Report)
Shows key metrics for the selected week:

- **New Applicants** - Total applications received this week
- **Approved** - Applications approved this week
- **Pending** - Applications waiting for approval
- **Rejected** - Applications rejected this week
- **Amount Released** - Total assistance amount paid out

### Daily Breakdown Charts

#### 1. Daily Applicants Chart
```
Shows: Bar chart of new applications per day
Helps: Identify busy days and appointment scheduling needs
Pattern: See which days get most applications
```

#### 2. Daily Amount Released Chart
```
Shows: Line graph of amount paid each day
Helps: Track weekly spending patterns
Pattern: Monitor budget distribution throughout week
```

#### 3. Applicants by Assistance Type
```
Shows: Doughnut chart (pie chart) breakdown
Includes: Medical, Burial, OPD
Helps: Understand which programs are busiest
```

#### 4. Amount by Assistance Type
```
Shows: Bar chart of spending by program
Includes: Medical, Burial, OPD
Helps: Monitor budget allocation per program
```

## 🗓️ Week Selection

### How Week Numbers Work
```
Week 1:  December 27, 2025 - January 2, 2026
Week 2:  January 3 - January 9, 2026
Week 3:  January 10 - January 16, 2026
...
Week 52: December 21 - December 27, 2026
```

### Selecting Different Weeks
1. Click the **"Week"** dropdown
2. Each week shows:
   - Week number (e.g., "Week 15")
   - Date range (e.g., "Mar 30 - Apr 05")
3. Select the week you want to review
4. Report automatically updates

### Current Week vs. Past Weeks
- **Default:** Shows current week automatically
- **Past Weeks:** Select from dropdown to view historical data
- **Future Weeks:** Cannot view future weeks (no data)

---

## 🔄 Year Selection

### Important: Year & Week Together
When selecting a week, ensure the **Year** matches:

1. Select **Year** (2025, 2026, 2027, etc.)
2. Then select **Week** from that year
3. Days shown will be from that specific year/week combination

### Example:
```
Year: 2026
Week: 15 (March 30 - April 5, 2026)
→ Chart shows March 30, 31, April 1-5 data only
```

## 📊 Understanding the Charts

### Bar Chart (Daily Applicants)
```
𝘠-axis: Number of applicants
𝘹-axis: Days of week (Mon, Tue, Wed, etc.)
What it shows: Which days are busiest
Use for: Scheduling staff and appointments
```

### Line Chart (Daily Amount Released)
```
𝘠-axis: Amount in Philippine Peso (₱)
𝘹-axis: Days of week
What it shows: Daily spending distribution
Use for: Budget tracking and forecasting
```

### Doughnut Chart (By Type)
```
Segments: Medical (large), Burial (medium), OPD (small)
Size: Represents percentage of total
What it shows: Which programs serve more people
Use for: Resource allocation decisions
```

### Bar Chart (Amount by Type)
```
Bars: One for each assistance type
Height: Amount of money released
What it shows: How budget is distributed
Use for: Budget justification
```

## 🎯 Key Metrics to Track Weekly

### Approval Rate
```
Formula: (Approved / Total) × 100
Goal: > 70%
Meaning: How many applications are approved
```

### Average Assistance Amount
```
Formula: Total Amount Released / Approved Count
Goal: Varies by program
Meaning: Average help per person
```

### Processing Time
```
Measure: Date approved - Date applied
Goal: < 7 days
Meaning: How fast we process
```

### Program Distribution
```
Track: Which program gets most applications
Meaning: Where to focus resources
```

## ⚠️ Troubleshooting

### No Data Showing?
```
Check:
1. Week is correct
2. Year matches the week
3. Data exists for that week
4. Filter hasn't excluded needed data

Fix:
- Change year
- Change week
- Check if data entry complete
```

### Charts Not Displaying?
```
Check:
1. Browser is supported (Chrome, Firefox, Safari, Edge)
2. JavaScript is enabled
3. Internet connection is active

Fix:
- Refresh page (F5)
- Clear browser cache
- Try different browser
```

### Can't Find Week?
```
Example:
- January 2026 starts on Week 1
- Clicking week 1 shows Jan 3-9 or so
- Some December dates may be in Week 52 of previous year

Solution:
- Use calendar to count weeks
- Check date range in dropdown
- Count backwards from current week
```
